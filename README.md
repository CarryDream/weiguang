# 微光

微光是一只停在 Windows 桌面上的黑白小圆团。它会看着鼠标、陪你待一会儿；你在忙的时候，它也可以安静地待在一边。

## 桌面上能做的事

- **陪伴**：眼神跟着鼠标，可以拖动、做表情，也能贴在屏幕边上。系统托盘里可以显示或藏起它。
- **待办事项**：记下要做的事，勾掉完成的，设置时间和重复，也可以开始一段 25 分钟专注。
- **便签**：另外开几张小便签，调整颜色和字号。内容保存在这台电脑上，重启后还在。
- **小表演和问候**：可以看一段短表演，例如散步、采花或小火箭，也会在早晚打个招呼。
- **健康提醒**：久坐、看看远处、喝水。间隔和免打扰时间可以在设置里改。
- **陪伴手记**：想聊天、记下记忆或看看习惯时再打开。不配置 AI 也能使用上面的本地功能。

## 下载

安装包在 [Releases](https://github.com/CarryDream/weiguang/releases)。

- `Weiguang-Setup-<版本>-x64.exe`：安装版
- `Weiguang-Portable-<版本>-x64.exe`：便携版
- `SHA256SUMS.txt`：两个安装文件的 SHA-256

下载后先用校验文件核对。安装包没有代码签名时，Windows 可能提示未知发布者。已经安装过的话，升级前先在应用的设置里导出完整备份。

这个仓库只发布安装包。
